# Firebase Firestore Structure

This document describes the Firestore database structure for EduAgent.

## Collections

### 1. `users` Collection

Stores user account information for all roles (student, teacher, individual).

**Document ID**: User's Firebase Auth UID

**Fields**:

| Field Name | Type | Required | Description |
|------------|------|----------|-------------|
| `uid` | string | Yes | Firebase Auth UID (same as document ID) |
| `email` | string | Yes | User's email address |
| `name` | string | Yes | User's full name |
| `role` | string | Yes | User role: `"student"`, `"teacher"`, or `"individual"` |
| `photoURL` | string | No | URL to user's profile picture (from Google sign-in) |
| `createdAt` | timestamp | Yes | Account creation timestamp |
| `updatedAt` | timestamp | Yes | Last update timestamp |
| `emailVerified` | boolean | No | Whether email is verified |

**Example Document**:
```json
{
  "uid": "abc123xyz789",
  "email": "teacher@example.com",
  "name": "John Doe",
  "role": "teacher",
  "photoURL": "https://lh3.googleusercontent.com/...",
  "createdAt": "2024-01-15T10:30:00Z",
  "updatedAt": "2024-01-15T10:30:00Z",
  "emailVerified": true
}
```

### 2. `lessons` Collection

Stores lesson content generated by EduAgent for teachers.

**Document ID**: Auto-generated lesson ID (e.g., `"lesson_abc123xyz"`)

**Fields**:

| Field Name | Type | Required | Description |
|------------|------|----------|-------------|
| `uid` | string | Yes | Lesson unique identifier (same as document ID) |
| `teacherId` | string | Yes | Firebase Auth UID of the teacher who created the lesson |
| `title` | string | Yes | Lesson title (e.g., "Photosynthesis – Grade 5") |
| `grade` | string | Yes | Grade/Level (e.g., "Grade 5", "University", "Adult") |
| `subject` | string | Yes | Subject (e.g., "Science", "Mathematics", "History") |
| `duration` | string | No | Lesson duration (e.g., "45 minutes") |
| `learningObjectives` | array<string> | No | Array of learning objectives |
| `studentSummary` | string | Yes | Student-facing summary/content (first string) |
| `teacherGuidelines` | string | Yes | Teacher-facing guidelines and notes (second string) |
| `slidesUrl` | string | Yes | URL to the generated slides/presentation |
| `status` | string | Yes | Lesson status: `"draft"`, `"fact-check needed"`, or `"ready"` |
| `factCheckStatus` | string | No | Fact-check status: `"High confidence"`, `"Needs review"`, or `"Check critical issues"` |
| `factCheckStats` | object | No | Fact-check statistics (see below) |
| `flaggedIssues` | array<object> | No | Array of flagged issues from fact-checking (see below) |
| `sources` | object | No | Source materials used (see below) |
| `createdAt` | timestamp | Yes | Lesson creation timestamp |
| `updatedAt` | timestamp | Yes | Last update timestamp |
| `lastModified` | timestamp | Yes | Last modification timestamp (for sorting) |

**factCheckStats Object**:
```json
{
  "claimsVerified": 45,
  "totalClaims": 48,
  "outdatedFacts": 2,
  "unsupportedStatements": 1
}
```

**flaggedIssues Array Item**:
```json
{
  "id": "issue_123",
  "claim": "Photosynthesis occurs only during daylight hours",
  "severity": "warning", // or "critical"
  "section": "studentSummary", // or "teacherGuidelines"
  "position": 150 // character position in text
}
```

**sources Object**:
```json
{
  "files": [
    {
      "name": "textbook.pdf",
      "url": "gs://bucket/textbook.pdf",
      "uploadedAt": "2024-01-15T10:30:00Z"
    }
  ],
  "textContent": "Pasted textbook excerpt...",
  "useCurriculumStandards": true,
  "useReputableSites": true,
  "customUrls": ["https://example.com", "https://another-site.org"]
}
```

## Security Rules Recommendations

### Users Collection
```javascript
match /users/{userId} {
  allow read: if request.auth != null;
  allow write: if request.auth != null && request.auth.uid == userId;
}
```

### Lessons Collection
```javascript
match /lessons/{lessonId} {
  allow read: if request.auth != null;
  allow create: if request.auth != null && 
    request.resource.data.teacherId == request.auth.uid;
  allow update, delete: if request.auth != null && 
    resource.data.teacherId == request.auth.uid;
}
```

## Indexes

### Lessons Collection

**Composite Index for Recent Lessons Query**:
- Collection: `lessons`
- Fields: `teacherId` (Ascending), `lastModified` (Descending)

**Composite Index for Subject/Grade Filtering**:
- Collection: `lessons`
- Fields: `teacherId` (Ascending), `subject` (Ascending), `grade` (Ascending)

## Notes

1. **Document IDs**: 
   - Users: Use Firebase Auth UID directly
   - Lessons: Use auto-generated IDs with prefix (e.g., `lesson_`)

2. **Timestamps**: All timestamps should use Firestore's `serverTimestamp()` for consistency

3. **File Storage**: Uploaded files should be stored in Firebase Storage, and URLs should be saved in the `sources.files` array

4. **Slides**: Generated slides can be stored as:
   - PDF files in Firebase Storage (recommended)
   - Google Slides URLs (if integrated)
   - HTML/JSON format for web-based presentations

5. **Status Flow**: 
   - `draft` → Created but not fact-checked
   - `fact-check needed` → Fact-checking found issues
   - `ready` → Approved and ready to use

6. **Data Validation**: Consider using Cloud Functions to validate data structure and enforce business rules
